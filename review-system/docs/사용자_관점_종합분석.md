시험 자료는 기존 합성 fixture를 사용하고 실서비스 데이터 수집으로 늘리지 않습니다. 서버 규칙은 실제 MySQL 통합시험, JSP 표현은 브라우저 DOM, 시각 배치는 캡처로 나눕니다. 같은 로직을 그대로 베낀 단위시험이나 Repov와 숫자가 같아야 한다는 시험은 추가하지 않습니다. 기존 이력 시험이 이미 다룬 경계는 중복 작성하지 않습니다.

### 재사용 후의 완료 판단

현재 제품은 범위 표시 외의 새 기능을 더 넣기보다 유지하는 편이 낫습니다. 공통 조각(history-summary/rating-change/record-list/filter), 저장 영향 설명, 집계 단위는 다음 팀원이 재사용할 계약입니다. 남은 일은 기능 수 확대가 아니라 독립 검산·실기기·스크린리더 검토입니다. 새로운 화면을 만들 때는 숨은 필터를 표시하고, 선택 입력과 실제 저장 영향을 명시하고, NULL/0·이벤트/작품·기간/전체의 구분을 기존 서버 계약에 연결해야 합니다. 자세한 인수 체크는 [team-handover.md](team-handover.md), 채택 이유는 [design.md](design.md), 이번에 실행한 검증만의 범위는 [verification.md](verification.md)에 통합했습니다.
